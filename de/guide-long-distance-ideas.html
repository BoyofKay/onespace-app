15 kleine Möglichkeiten, sich in einer Fernbeziehung nah zu fühlen

6 Min. gelesen · OneSpace

Distanz zerstört eine Beziehung selten in einem großen Moment. Es zermürbt es in kleinen Momenten: ein verpasster Anruf, ein Tag, den Sie nicht teilen konnten, ein Plan, der ins Wanken geraten ist. Auch die Lösung ist klein – eine Handvoll Rituale, die Sie monatelang durchhalten können. Hier sind fünfzehn, an die sich Paare tatsächlich halten.

Respektieren Sie die Uhr des anderen

  1. Informieren Sie sich über die dortige Uhrzeit, bevor Sie anrufen. Ein kurzer Blick erspart viel „Entschuldigung, habe ich Sie geweckt?“
  2. Vereinbaren Sie eine „goldene Stunde“ pro Tag, in der Sie wach und frei sind – und schützen Sie sie.
  3. Senden Sie Nachrichten, die keiner Antwort bedürfen, etwa „Ich denke an Sie“. Sie landen ohne Druck.

Teilen Sie die langweiligen Teile

  1. Führen Sie eine gemeinsame Liste – Lebensmittel, Besorgungen, Geschenke. Den Alltag des anderen zu sehen, ist überraschend intim.
  2. Machen Sie täglich einen einminütigen Check-in: eine Stimmung und eine ehrliche Zeile über Ihren Tag.
  3. Tauschen Sie ein tägliches Selfie aus. In einem Monat haben Sie ein Tagebuch über die Distanz.

Immer den nächsten Termin haben

  1. Beenden Sie einen Besuch niemals ohne den nächsten Termin im Kalender, auch wenn dieser vorläufig ist.
  2. Zählen Sie es gemeinsam herunter. An schwierigen Tagen ist es ein echter Trost, zuzusehen, wie eine Zahl schrumpft.
  3. Planen Sie die Reise gemeinsam – Flüge, Packen, was Sie als Erstes tun werden. Planung ist die halbe Freude.

Machen Sie Liebe greifbar

  1. Schreiben Sie einen Brief, der an einem bestimmten Tag beginnt: ihrem Geburtstag, ihrer Prüfung, dem Tag ihrer Landung.
  2. Führen Sie eine Liste mit Orten, die Sie gemeinsam besuchen werden, und ergänzen Sie diese nach jedem Anruf.
  3. Schauen Sie sich den gleichen Film gleichzeitig an, bewerten Sie ihn dann separat und vergleichen Sie ihn.

Schützen Sie die Beziehung vor Logistik

  1. Verschieben Sie Entscheidungen aus dem Chat. Vergleichen Sie Optionen an einem Ort, damit sich Anrufe auf Sie beziehen können.
  2. Denken Sie an die wichtigen Daten – und an die, die nur für Sie beide wichtig sind.
  3. Sagen Sie Danke für die kleinen Dinge. Ein „Stolz auf dich“ geht weiter, als Sie denken.
