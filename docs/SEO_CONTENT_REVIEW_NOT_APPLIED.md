# SEO — implementation boundary and proposed content changes
Date: 2026-11-18.

## Already live / permitted technical work
- Canonical URLs, alternate language links (EN AR ES FR DE), sitemap, robots, accessible internal links, descriptive titles, and structured data are generated by the website build and checked in CI.
- Static website is on GitHub Pages at https://onespace.live; GoatCounter code is present for cookieless visits.
- These technical measures do **not** establish Google indexing, a rank, or Search Console ownership. `GOOGLE_VERIFY` and `BING_VERIFY` in the generator remain empty; a domain DNS verification may exist outside this repository, and needs separate verification.
- No paid backlinks, links farms, automated search submissions or unapproved domain changes.

## Proposed on-page **copy changes — NOT implemented**
Approval is required before changing page marketing language for SEO:
1. Home: clarify the first visible benefit for couples living apart **and** together with natural language; do not keyword-stuff the headline.
2. Living apart: one short answer about shared schedules, time zones, trips and reminders, tied to the existing scenarios (not a new article).
3. Living together: one short answer about mental load, shared chores and household decisions, linking to relevant journeys.
4. Feature pages: precise, platform-qualified descriptions rather than broad "any app" claims; see `FEATURE_PAGES_PROPOSAL_FOR_APPROVAL.md`.
5. Guides: editorial metadata should describe what the page genuinely teaches; not repeated search phrases.

## Can be done without copy approval
- Check for broken internal links, valid sitemap/alternate URLs, sensible indexing controls and no invented rating schemas (CI tests).
- Add context-appropriate links between genuine tutorials, guides, and scenarios.
- Prepare descriptive file names and genuine app screenshot alt texts.
- Collect search queries, impressions and index coverage **once** an authorized Google Search Console account is linked.
- Prepare a partner outreach target list and drafts, but never send unsolicited messages without an approved plan.

## External authority strategy — planning only
Seek permission-based, editorially relevant mentions from couples' communities, relationship educators, indie app directories and Android beta testing channels. Prioritize usefulness and clearly disclose the project owner's affiliation. No fabricated reviews or paid dofollow link schemes. Measure referral visits separately from indexed search traffic.

## Validation criteria after approval
Indexing coverage, page relevance, click-through rate, engaged sessions, founder sign-up completion, correct target language and truthful platform claims. Never promise first-page rankings.
