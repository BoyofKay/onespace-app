# OneSpace website

Public site for OneSpace, served free by GitHub Pages: https://boyofkay.github.io/onespace-app/

## How it is built
Every page is generated by **`build.py`** from one design system:

| File | What it is |
|---|---|
| `build.py` | All page copy (English + Arabic), the navigation, the footer and the phone illustrations |
| `content/legal.json` | Privacy policy and terms text (EN/AR), kept in step with the app |
| `assets/os.css` / `assets/os.js` | The only stylesheet and script: language switch, menu, theme switcher, tabs/demo, FAQ search, forms, share buttons |
| `assets/ar.js` | Generated Arabic strings — don't edit by hand |
| `assets/press/` | Marketing images, rendered by `tools/render_press.py` |
| `tests/check_site.py` | CI checks: one H1, descriptions, alt text, links and anchors, sitemap, redirects, forbidden claims |

Edit `build.py`, run `python3 build.py`, commit the generated files. CI fails if the HTML wasn't regenerated.
To refresh the images: `python3 tools/render_press.py` (needs Playwright and Chrome).

## Site map
Home (compact: hero → five-tab selector with themes → Founding 500 form) · Features · For couples (Living apart, Living together) · Demo (`how-it-works.html`, the 6-step "plan a weekend away" workflow) · Tutorials · FAQ · What's new + Where things stand · Founding 500 (`join.html`) · Support · Share kit · Privacy · Terms · Delete account · 404. `v4.html` and `v4-tutorial.html` redirect.

## Rules for content
- Illustrations are drawn in HTML/CSS with example people (Omar & Lina). Never publish real screenshots that contain personal data.
- Don't advertise retired or hidden features: automatic love gestures (D1) and voice commands (D55). CI blocks the phrases.
- Mark what is available now, in testing and planned (`AVAILABILITY` in `build.py`).
- Founder Member benefits are not defined yet — say they will be announced before any pricing.

## Forms
Founding 500, Support and Delete-account forms post to the Supabase RPC `submit_public_support` (the same inbox as the app; publishable key only). Founding 500 sign-ups arrive with subject `Founding 500 · <platform> · <living>` and include the sign-up time and where the visitor came from (UTM/referrer). Read them in Supabase → `public_support_requests`.

## Analytics (off)
Set `GOATCOUNTER` in `build.py` to a free GoatCounter code and rebuild. It's cookieless; CTA, tab and theme clicks are then counted as events. Add one line to the privacy policy when you turn it on.
