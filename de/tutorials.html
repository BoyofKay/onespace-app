Einfache Anleitungen Schritt für Schritt.

Kurze, praktische Anleitungen für die Dinge, die Paare am häufigsten tun. Möchten Sie es lieber sehen? Probieren Sie die Demo aus.

🚀 Erste Schritte☑️ Täglich🧭 Gemeinsam planen🔖 Merken🔒 Datenschutz & Hilfe

🚀 Erste Schritte

Gestalten Sie Ihren Raum und laden Sie Ihren Partner ein
  1. Melden Sie sich mit Ihrer E-Mail-Adresse an und akzeptieren Sie die kurzen Bedingungen.
  2. Gestalten Sie Ihren Raum und geben Sie ihm einen Namen.
  3. Teilen Sie den Einladungscode oder zeigen Sie den QR-Code vor.
  4. Ihr Partner meldet sich an und tippt auf „QR-Code Ihres Partners scannen“. Das ist alles – ein Raum bietet Platz für genau zwei Personen.
Sagen Sie OneSpace, wie Sie leben
  1. Tippen Sie in Ihrem Bereich auf „Erzählen Sie OneSpace, wie Sie leben“.
  2. Wählen Sie, ob Sie getrennt oder zusammen wohnen möchten. Apart fügt die Uhren und das Wetter beider Städte zu Today hinzu.
  3. Integrierte Gestennachrichten folgen Ihrer Wahl – keine langen Warteschlangen für Paare zu Hause.
Wählen Sie Ihre Sprache und Ihr Thema
  1. Öffnen Sie „Me“ und wählen Sie „Englisch“ oder „Französisch“ – jeder von Ihnen wählt separat.
  2. Wählen Sie eines von neun Themen und einen Hintergrund, der Ihnen gefällt.

☑️ Täglich

Fügen Sie alles in zwei Schritten hinzu
  1. Tippen Sie auf „Heute schnell hinzufügen“.
  2. Wählen Sie Erinnerung, Aufgabe, Ereignis, Notiz, Reise, Ort, Brief ...
  3. Wählen Sie, wem es gehört – Ihnen, Ihrem Partner oder beiden – und ob es „Geteilt“ oder „Nur ich“ ist.
Sehen Sie sich OneSpace-Ereignisse in Ihrem Telefonkalender an
  1. Aktivieren Sie „In meinem Telefonkalender anzeigen“ und erlauben Sie den Kalenderzugriff.
  2. Geteilte Ereignisse, Reisen, Anlässe und besondere Termine erscheinen in einem separaten „OneSpace“-Kalender im Google-, Samsung- oder iPhone-Kalender.
  3. Es gibt eine Möglichkeit: Ändern Sie Dinge in OneSpace, und OneSpace liest niemals Ihre anderen Kalender.
Sende ein wenig Liebe
  1. Öffnen Sie „Ein bisschen Liebe aus unserem Raum“ oder „Verbinden“.
  2. Wählen Sie eine Geste – umarmen, küssen, stolz auf Sie, rufen Sie mich an …
  3. Behalten Sie die integrierte Nachricht bei oder schreiben Sie eine eigene und senden Sie sie dann.

🧭 Gemeinsam planen

Entscheiden Sie gemeinsam mit einer Aktivität
  1. Erstellen Sie in Coordinate eine Aktivität – ein Sofa, ein Restaurant, einen Wochenendausflug.
  2. Fügen Sie Optionen mit Links und Preisen hinzu; Jeder von euch markiert, was ihm gefällt.
  3. Sprechen Sie im Gespräch (geben Sie „@“ ein, um es zu erwähnen, oder zeichnen Sie eine Sprachnotiz auf) und zeichnen Sie dann die Entscheidung auf.
  4. Verwenden Sie „Erinnern Sie uns“ oder fügen Sie es dem Kalender hinzu – die Elemente bleiben verknüpft.
Planen Sie eine Reise
  1. Erstellen Sie eine Reise unter Koordinaten → Reisen.
  2. Einen Flug gefunden? Tippen Sie in Google Flights auf „Teilen“ > „OneSpace“ oder kopieren Sie den Link und fügen Sie ihn ein.
  3. Teilen Sie die Packliste auf und fügen Sie Reisedokumente bei – nur Sie beide können sie öffnen.
Bereiten Sie einen Überraschungsanlass vor
  1. Erstellen Sie einen Anlass und stellen Sie ihn auf „Nur ich“ ein.
  2. Fügen Sie Geschenkideen mit Preisen und Budget hinzu.
  3. Wählen Sie, wann Sie mit der Vorbereitung beginnen möchten – OneSpace erinnert Sie rechtzeitig daran.

🔖 Merken

Countdown (oder Up) bis zu einem besonderen Datum
  1. Öffnen Sie Counters in Remember und fügen Sie ein Datum hinzu.
  2. Für ein vergangenes Datum sehen Sie sowohl die Zeit seit dem Tag selbst als auch den nächsten Jahrestag.
  3. Verwenden Sie „Mit einem anderen Zähler verknüpfen“, um die Zeit zwischen zwei Momenten anzuzeigen.
Speichern Sie einen Ort aus Google Maps
  1. Tippen Sie in Google Maps auf „Teilen“ › OneSpace (oder kopieren Sie den Link in den Ort).
  2. Wählen Sie „Been there“ oder „Bucket list“, fügen Sie Fotos, ein Datum und eine Notiz hinzu.
  3. Öffnen Sie die Karte, um alle Ihre Pins anzuzeigen. Kreuzen Sie Orte auf der Wunschliste an, um eine Reise zu planen.
Machen Sie ein Sammelalbum
  1. Wählen Sie eine Vorlage und fügen Sie Erinnerungen und Fotos hinzu.
  2. Laden Sie Ihren Partner ein, Seiten hinzuzufügen.
  3. Verwenden Sie „Als PDF speichern oder teilen“, um es zu behalten oder auszudrucken.

🔒 Datenschutz & Hilfe

Halten Sie etwas privat
  1. Wählen Sie beim Erstellen oder Bearbeiten eines Elements „Nur ich“ anstelle von „Geteilt“.
  2. Nur für mich bestimmte Artikel werden nie auf dem Telefon Ihres Partners angezeigt.
Exportieren oder löschen Sie Ihre Daten
  1. Öffnen Sie mich → Ihre Daten und Ihr Konto.
  2. Wenn Sie eine Kopie wünschen, exportieren Sie zuerst und tippen Sie dann auf Mein Konto löschen.
  3. Ausgesperrt? Benutzen Sie die Löschungsantragsformular.
Erhalten Sie Hilfe, wenn Sie sich nicht anmelden können
  1. Auf dem Anmeldebildschirm finden Sie Hilfe, Kontakt und Problem melden – kein Konto erforderlich.
  2. Oder nutzen Sie die Website-Formular; Wir antworten per E-Mail.

Nichts passt zusammen. Fragen Sie uns.
