# OneSpace website — https://onespace.live

The public website of OneSpace, the private app for couples ("Two of us, One Space"). English at `/page.html`, Arabic at `/ar/page.html`, Spanish at `/es/page.html`, French at `/fr/page.html`, and German at `/de/page.html`. All languages reuse the same full site layout and media. Served free by GitHub Pages on the custom domain **onespace.live** (`CNAME`).

## How it is built
Every page is generated by **`build.py`** from one design system. Edit `build.py`, run `python3 build.py` (needs `beautifulsoup4`), commit the generated files. CI fails if the HTML was not regenerated.

| File | What it is |
|---|---|
| `build.py` | Original English/Arabic website, navigation, shared layout, SEO tags, sitemap, robots, llms.txt, generated locale siblings |
| `content/deep_pages.py` | The 7 feature deep pages (problem → steps → details → before/after → FAQ) and the comparison table |
| `content/legal.json` | Privacy policy and terms (EN/AR), kept in step with the app |
| `assets/os.css`, `assets/os.js` | The only stylesheet and script: menu, language, theme switcher, demo tabs, forms, analytics events, confirmation/unsubscribe pages, admin dashboard |
| `assets/ar.js` | Generated Arabic strings — don't edit by hand |
| `content/full_localization.py` | Source-equivalent Spanish/French/German pages using the original screenshots, phone walkthrough, theme switcher, forms and analytics |
| `content/locale_editorial.py` | Human-authored Spanish/French/German terminology and marketing copy polish |
| `content/translations/` | Versioned multilingual translation catalogues (no live translation calls) |
| `assets/app/` | Real app screens and clips of the fictional demo couple (Omar & Lina), imported by `tools/import_screens.py` from the `app-screens` branch |
| `assets/press/` | Store and social images, rendered by `tools/render_press.py` (previews in `assets/press/preview/`) |
| `backend/founders/` | Source of the Founder waitlist backend (SQL + Supabase Edge Functions). Secrets live only in Supabase |
| `tests/check_site.py` | CI: one H1, descriptions, alt text, links, source-equivalent visuals/interactions and anchors (EN/AR/ES/FR/DE), sitemap, redirects, forbidden claims |

## Founder Members waitlist
- One Founder number **per couple**; the first **250 confirmed couples (500 people)** are Founders, later couples go on a waitlist.
- Sign-up → confirmation email (Resend, from `founders@onespace.live`) → `confirm.html` gives the number and the partner invite link (`join.html?invite=…`).
- Data: Supabase project **OneSpace Production** (`letcgxbnblohhfyeuigz`), `private.founder_*` tables (service role only). Details: `backend/founders/README.md`.
- Invite waves, nudges and surveys are run from the private Command Center repo (`Onespace_command`).

## Analytics and SEO
- GoatCounter (`onespace`), cookieless. Only the page path is counted (no query string or #fragment). Events are fixed names (`cta/*`, `founders/*`, `demo/*`, `theme/*`, `lang/*`, `outbound/*`) — never form values. Live check: Actions › `analytics-check`.
- Canonical + reciprocal hreflang (en, ar, es, fr, de, x-default) on every page, sitemap covering all five languages, Organization/WebSite/MobileApplication/FAQPage/Article structured data, `llms.txt`, IndexNow ping after every publish (Actions › `indexnow`).

## Translation maintenance
- Read [Internationalization and QA policy](docs/INTERNATIONALIZATION.md). All ES/FR/DE pages reuse the original full English HTML, not separate mini-landing pages.
- Keep the language catalogues and editorial glossary updated after English copy changes, run `python3 build.py`, then `python3 tests/check_site.py` and `node --check assets/os.js`.
- Founder confirmation emails are currently in English/Arabic only; the translated forms state this clearly.

## Rules for content
- Only the fictional demo couple appears in screens. Never publish real screenshots or personal data.
- Global audience: no country-specific places, currencies, holidays or platforms.
- Don't advertise retired or hidden features: automatic love gestures (D1), voice commands (D55). CI blocks the phrases.
- Founder benefits are not defined yet — "announced before any pricing". No invented testimonials or numbers.

## Workflows
`site-check` (every PR) · `indexnow` (after publishing) · `analytics-check` and `founders-e2e` (manual live checks) · `app-screens` (screenshot robot, runs the app on an emulator).
